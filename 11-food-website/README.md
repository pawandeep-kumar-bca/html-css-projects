# 🍸 Lavender Lounge Website

A modern and responsive **restaurant/lounge website** built using **HTML & CSS**.
This project showcases a stylish UI for a lounge/bar including sections like hero, events, gallery, and booking.

---

## ✨ Features

* 🎨 Modern and elegant UI design
* 📱 Fully responsive (mobile + desktop)
* 🧭 Navigation bar with menu
* 🖼️ Image gallery layout (grid-based)
* 📅 Events section with cards
* 📍 Contact & timing section
* 📢 Call-to-action (Book Table / Contact)

---

## 🛠️ Tech Stack

* **HTML5**
* **CSS3 / SCSS**
* **Remix Icons**
* **Google Fonts**
