# 🚧 Coming Soon Page

A modern and minimal **Coming Soon / Launch Page UI** built using **HTML & CSS**.
This project is perfect for showcasing a website under development with a countdown timer and email subscription form.

---

## ✨ Features

* ⏳ Countdown timer UI (Days, Hours, Minutes, Seconds)
* 📧 Email subscription input
* 🎨 Clean dark theme design
* 📱 Centered responsive layout
* 🔘 Call-to-action button (Notify Me)
* 🌐 Social media icons

---

## 🛠️ Tech Stack

* **HTML5**
* **CSS3 / SCSS**
* **Flexbox**
* **Remix Icons**
* **Google Fonts**
