# 🍎 Product Card UI

A modern and visually appealing **Product Card Component** built using **HTML & CSS**.
This project showcases a product (apples) with images, color options, pricing, and details in a stylish layout.

---

## ✨ Features

* 🖼️ Product image showcase
* 🎨 Color selection preview
* 💰 Price display
* 📋 Product benefits list
* ❤️ Wishlist & share icons
* 🔘 Add to Cart button
* 🎯 Clean and modern UI

---

## 🛠️ Tech Stack

* **HTML5**
* **CSS3 / SCSS**
* **Flexbox**
* **Remix Icons**

## 🎨 Customization

You can easily modify:

* 🖼️ Product images (inside `/assets`)
* 💰 Price:

```html

```

* 🎨 Colors:

```css

```

* 📋 Product details & benefits
