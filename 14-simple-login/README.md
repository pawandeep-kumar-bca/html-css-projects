# 🔐 Login & Register Page

A clean and modern **Authentication UI (Login & Register Pages)** built using **HTML & CSS**.
This project includes both **user registration** and **login form** with a minimal dark-themed design.

---

## ✨ Features

* 🔑 Login & Register pages
* 🎨 Clean dark UI design
* 📱 Centered responsive layout
* ✏️ Input fields with custom styling
* 🔘 Stylish buttons with hover-ready structure
* 🔗 Navigation between Login & Register pages

---

## 🛠️ Tech Stack

* **HTML5**
* **CSS3 / SCSS**
* **Flexbox**

## 🎨 Customization

You can easily change:

* 🎨 Background color:

```css
background-color: #d3d3d3;
```

* 🎨 Form colors:

```css
background-color: #121212;
```

* 🔘 Button colors:

```css
background-color: #6200ee;
```

* ✏️ Input styles & placeholders
