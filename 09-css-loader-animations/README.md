# ⏳ CSS Loader Animation

A simple and smooth **loading spinner animation** built using pure **HTML & CSS**.
This project demonstrates how to create a circular loader using `border` and `@keyframes`.

---

## ✨ Features

* 🔄 Smooth infinite rotation animation
* ⚡ Lightweight (no JavaScript required)
* 🎯 Pure CSS implementation
* 🎨 Easy to customize colors & size
* 📱 Works on all modern browsers

---

## 🛠️ Tech Stack

* **HTML5**
* **CSS3 (Animations & Keyframes)**

## ⚙️ How It Works

* A circular shape is created using `border-radius: 50%`
* One side of the border is colored differently
* `@keyframes` rotates the element continuously

```css
@keyframes spin {
  0% { transform: rotate(0deg); }
  100% { transform: rotate(360deg); }
}
```
