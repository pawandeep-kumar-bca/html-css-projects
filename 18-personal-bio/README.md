# 👤 Personal Bio Page

A simple and elegant **Personal Bio Web Page** built using **HTML & CSS**.
This project showcases personal information, skills, and background in a clean and readable layout.

---

## ✨ Features

* 👤 Personal introduction section
* 🧾 About me description
* 📍 Location and background info
* 🧠 Skills and experience highlights
* 📋 Key elements section (structured list)
* 🔗 Social link (LinkedIn)
* 🎨 Dark theme design

---

## 🛠️ Tech Stack

* **HTML5**
* **CSS3 / SCSS**
* **Remix Icons**
