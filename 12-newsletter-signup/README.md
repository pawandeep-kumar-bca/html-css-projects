# 📩 Newsletter Signup Page

A modern and visually appealing **Newsletter Signup UI** built using **HTML & CSS**.
This project features a clean subscription form with creative background visuals and a centered layout.

---

## ✨ Features

* 📬 Clean and modern subscription UI
* 🎨 Attractive background with gradient colors
* 🖼️ Creative inbox illustration design
* 📱 Responsive centered layout
* ✏️ Input field with icon
* 🔘 Stylish submit button with gradient

---

## 🛠️ Tech Stack

* **HTML5**
* **CSS3 / SCSS**
* **Remix Icons**

## 🎨 Customization

You can easily change:

* 🎨 Background color:

```css
background-color: #f8795f;
```

* 📧 Input placeholder text
* 🔘 Button gradient:

```css
background: linear-gradient(#fc3c52, #f57d5d);
```
