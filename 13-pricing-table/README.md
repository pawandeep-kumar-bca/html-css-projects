# 💳 Pricing Table UI

A modern and attractive **Pricing Table Component** built using **HTML & CSS**.
This project displays multiple pricing plans (Basic, Standard, Premium) with a clean layout and gradient styling.

---

## ✨ Features

* 💰 Multiple pricing plans (Basic, Standard, Premium)
* 🎨 Beautiful gradient buttons
* 📊 Structured feature comparison
* 🖥️ Centered layout using Flexbox
* ⚡ Lightweight (no JavaScript required)
* 🎯 Clean UI suitable for real products

---

## 🛠️ Tech Stack

* **HTML5**
* **CSS3 / SCSS**
* **Flexbox**
* **Remix Icons (optional)**

## 🎨 Customization

You can easily modify:

* 💰 Pricing:

```html
<h1>$ 2.99</h1>
```

* 🎨 Gradient colors:

```css
background: linear-gradient(to left bottom, rgb(19 207 139), rgb(1 118 180));
```

* 📋 Features text

* 🧾 Plan names (Basic / Standard / Premium)
