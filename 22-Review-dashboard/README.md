# 📊 Review Analytics Dashboard

A modern and responsive **Review Dashboard UI** built using **HTML & CSS**.  
It displays review statistics, filters, and customer feedback in a clean dashboard layout.

---

## 🚀 Features

- 📊 Dashboard overview (Total, Positive, Negative, Avg Rating)
- 📦 Sidebar navigation (Dashboard, Reviews, Products, Settings)
- 🔍 Search bar for filtering reviews
- 🎯 Filter buttons (Amazon, Flipkart, Ratings)
- 💬 Review cards with status badges (Positive / Negative)
- 🎨 Modern UI with glassmorphism & dark theme
- 📱 Fully responsive layout

---

## 🛠️ Tech Stack

- HTML5  
- CSS3 (Flexbox + Grid)  
- CSS Variables  
- Modern UI Design
