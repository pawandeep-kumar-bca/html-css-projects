# 📰 Blog Layout UI

A modern and structured **Blog Layout design** built using **HTML and SCSS**.
This project focuses on creating a clean blog-style UI with multiple sections and responsive layout.

---

## 🚀 Features

* Multi-section blog layout 📑
* Responsive design 📱💻
* Clean typography and spacing ✨
* Image-based content sections 🖼️
* Flexbox-based layout system

---

## 🛠️ Tech Stack

* HTML5
* SCSS (CSS Preprocessor)

---
