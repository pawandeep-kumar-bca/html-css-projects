# 🚀 Portfolio Landing Page

A modern and responsive **Portfolio Landing Page** built using **HTML & CSS**.
This project showcases a personal introduction section with a clean UI, typography, and creative circular design.

---

## 📌 Features

* ✨ Clean and modern UI design
* 📱 Responsive layout (can be extended further)
* 🎨 Stylish typography using Google Fonts
* 🔘 Custom buttons with hover-ready structure
* 🟡 Decorative circular UI elements
* 👤 Profile image section with layered circles

---

## 🛠️ Tech Stack

* **HTML5**
* **CSS3**
* **Remix Icons**
* **Google Fonts**
