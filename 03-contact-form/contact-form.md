# 📩 Contact Form UI

A clean and modern **Contact Form design** built using **HTML and SCSS**.
This project focuses on creating a user-friendly form interface with proper layout and styling.

---


## 🚀 Features

* Clean and minimal UI ✨
* Input fields with icons (Remix Icons)
* Responsive centered layout 📱💻
* Styled form inputs and textarea
* Simple and user-friendly design

---

## 🛠️ Tech Stack

* HTML5
* SCSS (CSS Preprocessor)
* Remix Icons
