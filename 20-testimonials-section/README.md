# 💬 Testimonials Section UI

A modern and clean **Testimonials Section** built using **HTML & CSS**.
This project displays user feedback with ratings, navigation arrows, and a centered layout—perfect for landing pages.

---

## ✨ Features

* ⭐ Star rating display
* 💬 Customer testimonial text
* 👤 User name & designation
* 🎨 Clean dark theme UI
* ⬅️➡️ Navigation arrows (UI only)
* 📱 Centered responsive layout

---

## 🛠️ Tech Stack

* **HTML5**
* **CSS3 / SCSS**
* **Flexbox**
* **Remix Icons**
