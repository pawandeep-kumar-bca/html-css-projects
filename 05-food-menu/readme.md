# 🍔 Food Menu Page

A modern and visually appealing **Food Menu UI** built using **HTML and SCSS**.
This project showcases a restaurant-style menu with interactive cards and clean layout.



---

## 🚀 Features

* Responsive menu layout 📱💻
* Interactive food cards with hover effects ✨
* Category navigation menu 🧭
* Star rating UI ⭐
* Clean and modern design

---

## 🛠️ Tech Stack

* HTML5
* SCSS (CSS Preprocessor)
* Remix Icons
