# 🎓 Learn Hub - Online Learning Platform UI

A modern and responsive **Learning Platform Landing Page** built using **HTML and SCSS**.
This project showcases a complete educational website layout with multiple sections like hero, courses, testimonials, FAQ, and blog.

---

## 🚀 Features

* Fully responsive layout 📱💻
* Multi-section landing page
* Hero section with CTA buttons 🚀
* Course showcase section 📚
* Testimonials & student feedback ⭐
* FAQ section
* Newsletter subscription UI 📩
* Footer with contact details

---

## 🛠️ Tech Stack

* HTML5
* SCSS (CSS Preprocessor)
* Font Awesome Icons
