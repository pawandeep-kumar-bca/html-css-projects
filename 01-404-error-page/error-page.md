# 🚫 404 Error Page

A clean and modern **404 Error Page UI** built using **HTML and SCSS**.
This page is designed to inform users when a page is not found, with a simple and user-friendly layout.

---

## 🚀 Features

* Responsive design 📱💻
* Gradient background UI 🎨
* Clean typography ✨
* Button with icon (Remix Icon)
* Centered layout using Flexbox

---

## 🛠️ Tech Stack

* HTML5
* SCSS (CSS Preprocessor)
* Remix Icons
