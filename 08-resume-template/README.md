# 📄 Resume Template (HTML & CSS)

A clean and professional **Resume Template** built using **HTML & CSS**.
This project is designed to showcase personal details, education, experience, skills, and references in a structured and visually appealing format.

---

## ✨ Features

* 📌 Minimal & professional resume layout
* 🧾 Structured sections (About, Education, Experience, Skills, References)
* 🎨 Clean typography and spacing
* 📱 Print-friendly design
* 🔧 Easy to customize content

---

## 🛠️ Tech Stack

* **HTML5**
* **CSS3**
* **Remix Icons**

## 📑 Sections Included

* 👤 **Header**

  * Name
  * Role/Title

* 📞 **Contact Info**

  * Phone
  * Address
  * Email

* 🧠 **About Me**

  * Short introduction

* 🎓 **Education**

  * Degree
  * University
  * Year

* 💼 **Experience**

  * Job roles
  * Company
  * Description

* 🛠️ **Skills**

  * Soft & technical skills

* 📌 **References**

  * Contact details of references
